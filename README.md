# LCCS

This contains information and code snippets of relevance to Leaving Certificate Computer Science.

## Layout

Section C (programming) answers, one file per question part, named to match the SEC's own convention:

```
Exams/<year>/Higher/Question16_A.py
Exams/<year>/Higher/Question16_B.py
MockExams/<provider>/<year>/Higher/Question16_A.py
MockExams/<provider>/<year>/Higher/Question16_B.py
```
